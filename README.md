# WhatsApp Text Chat

Небольшой React-интерфейс для личной текстовой переписки в WhatsApp через GREEN-API.

## Возможности

- Подключение к авторизованному WhatsApp-инстансу.
- Открытие личного чата по номеру через CheckWhatsapp.
- Отправка текста и получение ответа через HTTP API.
- Понятные сообщения об ошибках и адаптивный интерфейс.

## Стек

React 19, TypeScript 5, Vite 7, CSS, npm.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

    npm install
    npm run dev
    npm run build

Проверки: npm run typecheck, npm run lint, npm run build.

## Подключение

1. Создайте **инстанс GREEN-API WhatsApp** в [личном кабинете](https://console.green-api.com/). Для входа нужны данные именно этого инстанса.
2. Авторизуйте его через WhatsApp на телефоне: «Связанные устройства» → «Привязка устройства» и QR-код в кабинете GREEN-API. [Официальная инструкция](https://green-api.com/docs/before-start/) описывает требования к телефону. Привязка по коду вместо QR тоже завершается в мобильном WhatsApp.
3. В настройках инстанса включите уведомления о входящих сообщениях (incomingWebhook) и оставьте webhookUrl пустым для HTTP polling.
4. В приложении введите idInstance и apiTokenInstance именно WhatsApp-инстанса. В дополнительной настройке при желании укажите apiUrl из его карточки; по умолчанию используется универсальный адрес https://api.green-api.com. Вход доступен и при выключенных уведомлениях; тогда в чате появится кнопка «Включить получение ответов».
5. Укажите номер адресата в международном формате без плюса и суффикса, например 79991234567. Нажмите «Открыть чат» и отправьте текст. Приложение само передаст GREEN-API номер с суффиксом @c.us.

## Как работает

apiUrl определяет хост для запросов к GREEN-API, а не учётную запись. [GREEN-API допускает универсальный адрес](https://green-api.com/docs/api/recommendations/using-green-api-hosts/), но рекомендует адрес из карточки инстанса для меньшей задержки и более стабильной работы.

- [GetStateInstance](https://green-api.com/docs/api/account/GetStateInstance/) проверяет авторизацию.
- [GetSettings](https://green-api.com/docs/api/account/GetSettings/) проверяет настройки. Если incomingWebhook выключен, [SetSettings](https://green-api.com/docs/api/account/SetSettings/) по нажатию кнопки включает только его. Для HTTP polling webhookUrl должен быть пустым; приложение не меняет этот адрес автоматически.
- [CheckWhatsapp](https://green-api.com/docs/api/service/CheckWhatsapp/) проверяет номер и возвращает chatId, включая возможный идентификатор @lid. Приложение передаёт номер как chatId вида номер@c.us и использует ID из ответа. Хотя документация допускает номер без суффикса, реальный инстанс вернул HTTP 400 с требованием суффикса.
- [SendMessage](https://green-api.com/docs/api/sending/SendMessage/) принимает chatId и текст до 20 000 символов. Ответ с idMessage означает постановку в очередь, а не доставку.
- [ReceiveNotification](https://green-api.com/docs/api/receiving/technology-http-api/ReceiveNotification/) отдаёт входящее событие. Приложение показывает личные текстовые сообщения с chatId вида @c.us, @lid или @id, в том числе текст со ссылкой и ответ с цитатой. [Обычный текст](https://green-api.com/docs/api/receiving/notifications-format/incoming-message/TextMessage/), [расширенный текст](https://green-api.com/docs/api/receiving/notifications-format/incoming-message/ExtendedTextMessage/).
- [DeleteNotification](https://green-api.com/docs/api/receiving/technology-http-api/DeleteNotification/) подтверждает обработку. Другие события пропускаются и удаляются из очереди.

src/App.tsx управляет экраном и данными вкладки, src/api/greenApi.ts содержит запросы и разбор ответов, src/hooks/useNotifications.ts последовательно опрашивает очередь. При выходе запрос отменяется. src/session.ts сохраняет параметры входа, список чатов и выбранный чат в sessionStorage только по выбору пользователя.

## Архитектура

Чаты и сообщения живут в React state. Один цикл polling запускается после входа при включённых входящих уведомлениях, обрабатывает события по одному и отменяется при выходе. Внизу боковой панели показаны время последней проверки очереди и счётчики событий без содержимого сообщений. Set идентификаторов в памяти вкладки защищает от повторного показа сообщения, если уведомление пришло повторно. Сетевой код отделён от UI, чтобы формы и разбор ответов можно было понимать независимо.

Загрузка истории чата и входящие уведомления — разные методы API. Однако [GetChatHistory](https://green-api.com/docs/api/journals/GetChatHistory/) тоже требует включённой настройки входящих сообщений; журнал может обновляться с задержкой до двух минут. Поэтому приложение получает новые ответы через уведомления.

## Безопасность и ограничения

GREEN-API становится связанным устройством WhatsApp и получает доступ к сообщениям, доступным этой сессии. Для тестирования разумно использовать отдельный аккаунт. После работы отвяжите устройство в WhatsApp → «Связанные устройства» и разлогиньте инстанс в GREEN-API. [Инструкция по подключению](https://green-api.com/docs/before-start/), [Logout](https://green-api.com/docs/api/account/Logout/).

Без флажка запоминания токен живёт только в памяти вкладки. С флажком он сохраняется в sessionStorage этой вкладки и вход перепроверяется после обновления страницы. Вместе с входом восстанавливаются только список открытых чатов и выбранный чат. Кнопка «Выйти» удаляет сохранённый вход и чаты. Это удобство имеет риск: любой JavaScript на том же origin может прочитать sessionStorage, поэтому не включайте запоминание на чужом компьютере. Токен также входит в URL запросов по контракту GREEN-API и виден в инструментах разработчика. [Поведение sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage), [рекомендации OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html).

При восстановлении входа приложение не дублирует проверку инстанса в React StrictMode. На временный HTTP 429 оно повторяет проверку с паузой и не удаляет сохранённый вход; при неверном токене или разлогиненном инстансе сохранённый вход удаляется. [Лимиты GREEN-API](https://green-api.com/docs/api/ratelimiter/).

При выключенном запоминании чаты после обновления пропадают. Переписка не сохраняется в обоих режимах, старая история не загружается. Поддерживаются личные текстовые сообщения; группы, медиа и статусы доставки не отображаются. Очередь уведомлений общая для инстанса, поэтому другой её потребитель может забрать событие. Отправка и получение сообщений проверены вручную с авторизованным WhatsApp-инстансом.
